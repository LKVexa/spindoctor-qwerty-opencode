# Changelog

## 1.1.0 — 2026-10-11

Updated the 3.0.3/four-tool integration to the unchanged SpinDoctor 3.1.2 engine 1.1.0 and six tools,
including the raw Markdown function table and file/text/chat theory tests. Replaced incompatible
extra exports with one plugin factory and declared the pinned OpenCode SDK dependency.
Added host-directory path resolution, cancellation, bounded child I/O, timeouts, Python probing,
serialized workspace updates and cache suppression. Added a preserve-and-merge installer and
owned-file uninstall, plus an independently generated alternative MCP configuration.
Both installation modes preserve the confirmation skill. Genuine Windows OpenCode 1.19.0 MCP
integration passed 13/13 and its full engine suite passed 12/12; SDK components passed 35/35 and
their engine suite passed 12/12.
Native CLI SDK resolution remained blocked despite an installed package; it is recorded as an
untested runtime boundary. Installer checks passed 24/24 with one Windows symlink fixture skipped.
